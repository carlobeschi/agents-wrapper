# shop-totals

A small order-total calculator used by an online shop: it adds up a basket,
applies a discount code and prints the amount charged.

    node src/cli.js data/sample-order.json
    node --test

## The report from support

> Since last week a few customers paid nothing at all for their order, and
> finance wants to know why. Others say their code "did nothing". Nobody has
> found a pattern yet. The order log is in `logs/orders.log`.
