# dynamicRef: $dynamicRef and $dynamicAnchor

The desk runs, in work/: `node ../checks/run-suite.js dynamicRef.json --skip-keywords=format,contentEncoding,contentMediaType,contentSchema,minProperties,maxProperties,dependentRequired,dependentSchemas,contains,minContains,maxContains,uniqueItems,unevaluatedItems,unevaluatedProperties`

It loads `validate` from work/validate.js and, for every test case in the files below, checks that
`validate(testCase.schema, test.data, testCase.externalSchemas || {})` returns exactly `test.valid`.
The test files are the official JSON Schema Test Suite (2020-12 cases only). You cannot read them; here is what they cover:

- dynamicRef.json: A $dynamicRef to a $dynamicAnchor in the same schema resource behaves like a normal $ref to an $anchor (2020); A $dynamicRef resolves to the first $dynamicAnchor still in scope that is encountered when the schema is evaluated (2020); A $dynamicRef with intermediate scopes that don't include a matching $dynamicAnchor does not affect dynamic scope resolution (2020); An $anchor with the same name as a $dynamicAnchor is not used for dynamic scope resolution (2020); after leaving a dynamic scope, it is not used by a $dynamicRef (2020); strict-tree schema, guards against misspelled properties (2020); tests for implementation dynamic anchor and reference link (2020); $ref and $dynamicAnchor are independent of order - $defs first (2020); $ref and $dynamicAnchor are independent of order - $ref first (2020); $ref to $dynamicRef finds detached $dynamicAnchor (2020); $dynamicRef skips over intermediate resources - direct reference (2020); $dynamicRef avoids the root of each schema, but scopes are still registered (2020); A $dynamicRef to an $anchor in the same schema resource behaves like a normal $ref to an $anchor; A $ref to a $dynamicAnchor in the same schema resource behaves like a normal $ref to an $anchor; A $dynamicRef without anchor in fragment behaves identical to $ref; A $dynamicRef without a matching $dynamicAnchor in the same schema resource behaves like a normal $ref to $anchor; A $dynamicRef with a non-matching $dynamicAnchor in the same schema resource behaves like a normal $ref to $anchor; A $dynamicRef that initially resolves to a schema with a matching $dynamicAnchor resolves to the first $dynamicAnchor in the dynamic scope; A $dynamicRef that initially resolves to a schema without a matching $dynamicAnchor behaves like a normal $ref to $anchor; multiple dynamic paths to the $dynamicRef keyword (2020); $dynamicRef points to a boolean schema
